# Anowix Technologies — MVP Website

This is the first frontend MVP using the supplied Anowix Technologies logo.

## Run
Open `index.html` in a browser, or serve the folder with any static web server.

## Included
- Responsive dark tech UI
- Home, Services, Internships, Webinars, Hackathons, Projects, Contact
- Registration/enquiry demo forms
- Browser-local demo storage
- Supplied Anowix logo
